DEBT TRACKER OS
1. Open index.html in a modern browser, or upload the folder contents to a static HTTPS host (for example GitHub Pages).
2. On Android Chrome, open the hosted URL, tap the browser menu, then Add to Home screen / Install app.
3. Data saves in that browser's local storage. Use BACKUP / EXPORT > DOWNLOAD JSON BACKUP regularly.
4. Import the JSON backup on another device/browser to restore.
5. Enter due dates in the Loan Register using EDIT. Browser notifications are checked when the app is opened; this static version cannot send dependable notifications while fully closed.
6. Cloud sync is not connected. A secure backend/authentication service is required for automatic cloud backup across devices.
Initial loan values are from the user's conversation and should be verified against current lender statements.
