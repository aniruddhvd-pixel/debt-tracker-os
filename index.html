[ DUE DATE REMINDERS ]

Add or update due dates from the loan register. The app checks upcoming dates when opened and can show browser notifications while the app is open and permission is granted.

A static web app cannot reliably send scheduled push notifications while fully closed. For dependable background reminders and automatic cloud sync, this app needs a connected cloud/backend service. Until then, use the backup export regularly and keep a phone calendar reminder for critical due dates.
[ DATA BACKUP & RESTORE ]

Your data is saved in this browser on this device. Export a JSON backup and keep it somewhere safe. Import that backup on another device to restore your register and history.

“Phone + cloud backup” is not connected in this version: no cloud account or server credentials were supplied. JSON backup/restore is included as a safe manual transfer method. Do not store bank passwords, OTPs, or sensitive credentials in this tracker.
